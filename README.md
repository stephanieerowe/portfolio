# Stephanie Rowe Portfolio

A responsive static portfolio site with:

- A home page with a hero, featured projects, freelance services, toolkit, AI integration, process, and contact sections
- An about page with background, values, and a personal timeline
- Shared styling and small JavaScript enhancements for navigation and scroll reveals

## Files

- `index.html` - main landing page
- `about.html` - about me page
- `styles/main.css` - shared styling
- `scripts/main.js` - navigation toggle, year, and reveal behavior
- `images/` - profile photos and site branding

## Running locally

Open `index.html` directly in a browser or serve the folder with any static server.

For example, with Python installed:

```bash
python -m http.server
```

Then visit `http://localhost:8000`.

## Deployment

This site has no build step and can be deployed to any static hosting provider, including GitHub Pages, Netlify, Vercel, or Azure Static Web Apps. Upload the project folder or connect the repository, keeping the existing file and folder structure intact.
